AI captions (Notasyon)

The consent dialog shows on first use. After approval, audio is transcribed in-browser — no bytes leave the device. This demo uses a deterministic fake engine so reviewers do not have to download the 39 MB Whisper model; the production binding lives in @bach/captions-ai/whisper. 


      


      

        
AI theme assist

        

          Describe a vibe in plain English; the playground builds the Claude API request a
          model would receive (system prompt + schema spec + the documented CSS variable
          contract). The request is shown verbatim so you can paste it into your own
          Anthropic SDK call, or pre-flight it through the public Workers AI gateway you ship
          alongside your director SPA.
        

        

          
          
        

        

      


      

        
GPU effects (Akustik)

        

          Pick a preset or build your own effect chain. The pipeline spec built here is the
          same data structure the WebGPU runtime consumes; on browsers without WebGPU the
          color-grade pass falls through to a Canvas-2D path so users still see _something_.
