## Planned API

```ts
import { createAudioMixer } from '@bach/audio-mix';

const mixer = createAudioMixer({
  context: new AudioContext(),
  master: hostVideoElement,
});

mixer.addTrack({ id: 'commentary', src: 'commentary.mp4' });
mixer.crossfade('main', 'commentary', { durationSec: 1.5, curve: 'equal-power' });

mixer.on('analyser', (frame) => {
  // 256-bin frequency data for the spectral overlay.
});
```

## Targets

- `AudioContext` graph with per-track `GainNode` + master bus.
- Master/slave time sync between tracks, drift target < 50 ms.
- Equal-power crossfader.
- Spectral analyzer overlay backed by `AnalyserNode`.
- Track add/remove at runtime without resync glitch.
