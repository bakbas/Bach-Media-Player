## The five signatures

<CardGrid>
  <Card title="Notasyon" icon="document">
    In-browser AI captions via Whisper + Transformers.js. Zero server,
    audio never leaves the device.
  </Card>
  <Card title="Hassasiyet" icon="setting">

  </Card>
  <Card title="Conducting" icon="rocket">

    viewer's UI in real time via signed, sandboxed theme manifests.
  </Card>

## Theming baseline

Underneath the five signatures sits a documented theming surface — CSS
variables, stable `::part()` names, slot composition, a `headless`
attribute, and a schema-strict `applyTheme()` runtime. The same parser
gates the Conducting protocol, so the security model is shared.

See [Theming](/theming/) for the full token catalogue.
